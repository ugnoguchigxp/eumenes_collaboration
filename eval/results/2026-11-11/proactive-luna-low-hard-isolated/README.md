# EvaluatorとSkill Smithの個別比較

[前回と同じ難問3課題](../proactive-luna-low-hard-paired/README.md)を、支援なし、Evaluatorのみ、SKILLのみ、両方ありの4条件で各2回、計24試行実行した。隔離した検証環境で、すべてのモデル呼び出しを `gpt-6-luna` の `low` に揃えた。課題、正解、Context Stillに登録した手順、Evaluatorと作成担当の指示は前回と同じ。条件の実行順は課題ごとにずらし、2回目は逆順とした。最大2組を並行実行した。 [事前登録](registration.json) · [凍結した課題と正解](cases.mjs)

各支援は、利用可能な条件で制作担当が自発的に選んだときに起動する。SKILLはContext Stillの登録済み手順を取得し、版を照合して渡す経路を使った。正答率は、判定・根拠や引当内訳・現行との差がすべて正しい行の割合。採点器は方式名を伏せた成果物を読み、各課題8行を判定する。完了時間は各試行開始から成果物確定まで。モデル使用量は接続が返した実測値を集計する。

## どの支援が効いたか

- **SKILLのみ**。対象となる欠品と公開承認の4試行すべてで手順を配達した。取消通知では候補を選択しなかった。欠品のS-05とS-06は、支援なしの両回で不足数をそれぞれ8個と6個としたが、SKILLのみの両回で正しい2個と1個になった。公開承認では、免除の終了時刻、締切後の承認ログ、依存先の停止連鎖の誤りが残った。
- **Evaluatorのみ**。6試行のうち3回起動し、指摘が成果物作成に届いたのは1回。ほかは時間切れ1回、未完了1回だった。完了した公開承認では、P-07の停止理由を「解禁待ち」から「依存先で停止」へ変更する指摘は正しかったが、根拠の連鎖は誤っていた。成果物も誤った連鎖 `P-05>P-06` を記載し、正解 `P-06>P-04` に届かなかった。欠品で改善したS-03とS-04の試行ではEvaluatorが起動していなかった。
- **両方あり**。支援なしからの正答の純増5行はすべて欠品で生じた。欠品の両回でSKILLが届き、Evaluatorは1回が未選択、もう1回が時間切れだった。全体ではEvaluatorが4回起動し、完了1回、未完了2回、時間切れ1回。SKILLは4回配達した。

今回の2反復で繰り返し観測できた改善は、欠品引当のSKILL利用時の不足数だった。Evaluatorのみは正答率の改善を確認できず、評価が成果物に届く回も限られた。各条件は支援を利用可能にしたときの成績であり、モデルが自発的に起動したかどうかも結果に含む。
