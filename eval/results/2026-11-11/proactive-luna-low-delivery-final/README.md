# 新規生成を使ったLuna lowの中間測定

前回と同じ合成6課題を、現行相当と支援ありで各1回実行した。全モデル呼び出しに `gpt-6-luna` の `low` を使用した。時間とモデル呼び出しの上限、実行順、並行数、採点基準を揃えた。課題文に評価やスキル利用の指定はない。 [事前登録](registration.json) · [課題と採点基準](../../../proactive/luna/cases.mjs)

[先行の対照試験](../proactive-luna-low-delivery/README.md)では、12試行とも完了し、両方式の基本得点は24/24点だった。Skill Smithは選択された4件とも配達に至らなかった。機材貸出は節IDを使わない補足の必須本文が欠け、他の3件は意味審査に通らなかった。Evaluatorは自発的に起動しなかった。

改修では、Skill Smithの生成出力を「そのまま利用」「補足」「組み合わせ」に分け、補足と組み合わせを選ぶ場合は本文を必須にした。Context Stillで取得した本文と版は生成前と配達前に照合する。生成と審査の結果は構造化出力で受け取り、出力の要点を試行記録に残す。個別試験で、検証例の負例が実際に拒否されず審査で失敗したことを確認したため、同じ検査関数に正例と負例を渡すよう生成指示を補った。 [機材貸出の個別試験](pilot-skill-equipment.json) · [欠品の個別試験](pilot-skill-stock.json)

Evaluatorでは、行の判定と指摘を一つの構造化出力にまとめた。根拠の位置は判定した行から設定する。前回の取消通知の誤指摘は、正常とした行が別の指摘一覧で違反とされたために生じた。改修後の個別試験では、正常なa/cを除き、誤送信のb/dだけを指摘した。個別試験は対照試験の集計から除いた。 [行判定の個別試験](../proactive-luna-low-delivery/pilot-review-rows.json)

## 結果

12試行すべて完了し、基本品質は両方式24/24点。支援ありではSkill Smithが4件選ばれた。適用候補なしが1件、生成後の意味審査で止まったものが3件で、配達は0件。Evaluatorは起動しなかった。 [集計](summary.json) · [試行記録](raw.jsonl)
