# Luna lowによる自発的支援の対照試験

合成6課題を1回ずつ、隔離した同一のexampleで現行相当と支援ありの両方式に実行した。どの依頼文にもEvaluatorやスキル利用の指定を入れていない。現行相当ではEvaluatorとSkill Smithを無効にした。同じ入力・モデル・成果物作成の指示を使い、支援ありではモデルが選んだ追加作業を通常返答の後に起動した。選んだ支援が並行して終了した時点で、完了した評価と配達済みスキルを成果物作成の参考資料にした。支援が不成立でも成果物作成は行う。

モデルは全工程で `gpt-6-luna`、推論設定は `low`。ログイン済みのCodex接続を使用した。課題ごとに実行順を交互にし、異なる2課題まで並行させた。制限は1回60秒、1試行180秒、現行2呼び出し、支援あり6呼び出しまで。事前の疎通確認は本測定の集計から除外した。 [事前登録](registration.json) · [課題・手順・採点基準](../../../proactive/luna/cases.mjs)

返答時間は依頼開始から通常返答確定まで、完了時間は同じ起点から成果物確定まで。環境と一時データの準備時間は含めない。モデル使用量は制作・評価・スキル生成と審査を含む。成果物は方式名を伏せ、各課題の固定4項目を各1点で採点する。Context Stillにだけある運用上の定型欄3件は別指標。支援が有用と事前に想定した課題区分は、実際の採否と比較するための目安である。

## 結果

| 指標 | 現行相当 | 支援あり |
| --- | ---: | ---: |
| 成果物が確定した課題 | 4/6 | 5/6 |
| 成果物の採点（未完了を0点） | 16/24 | 19/24 |
| 両方式が完了した4課題の採点 | 16/16 | 15/16 |
| 運用の定型欄を反映した課題 | 0/3 | 0/3 |
| 通常返答の中央値 | 6.81秒 | 6.49秒 |
| 成果物確定の中央値 | 17.71秒 | 16.49秒 |
| モデル呼び出し | 10 | 12 |
| 入力トークン | 87,558 | 106,165 |
| 出力トークン | 1,601 | 2,553 |

通常返答と成果物確定の中央値は、それぞれ確定した試行に限る。両方式が完了した課題は4件で、得点は3件が同点、1件が支援あり側で低かった。公開前の承認・例外は両方式で、予約上限と重複判定は現行相当で、2文上限を超えたため通常返答の確定前に停止した。予約上限の支援あり側は、追加支援を選ばず4点の成果物を返した。

Evaluatorは有用と見込んだ3課題のうち、通常返答を確定できた2件中1件で起動した。取消後の通知分岐では通知辞退時の誤送信設定を指摘し、取消なしの誤送信設定を見落とした。最終成果物も後者を要修正と扱わなかった。所要時間は現行相当18.62秒、支援あり36.27秒で、内訳の背景評価は11.86秒だった。

Skill Smithの選択は0件だった。有用と見込んだ3課題のうち機材貸出と欠品引継ぎでは通常返答まで進んだが、モデルはスキル検索を選ばなかった。残る1件は通常返答の確定前に停止した。今回の使用量にはSkill Smithの生成や配達の呼び出しが含まれない。

各課題は1反復で、採点は方式名を伏せた記録を同じ採点者が確認した。外部MCPの通信時間、スキルが選ばれた場合の品質と遅延、製品環境での性能は測定範囲外。 [集計](summary.json) · [全12試行](raw.jsonl) · [匿名化した成果物](blind.json) · [採点](grades.json)

## 再現

```sh
bun test example/proactive
bun eval/proactive/luna/run.mjs <隔離Eumenesホスト> <新規結果フォルダー>
bun eval/proactive/luna/summarize.mjs <採点済み結果フォルダー>
```

集計には、`blind.json` と課題ごとの4条件で採点した `grades.json` を使う。固定試験は既存分を含め200件通過し、型検査も通過した。
